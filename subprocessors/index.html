Subprocessors

Providers that process data to run ilming.

These are the providers ilming uses to run the platform. An institute’s live class links (Google Meet, Zoom, or another URL the institute pastes) are that institute’s own meetings and are not listed here. Last updated: 30 September 2026.

ProviderPurposeData
Amazon Web ServicesApplication hosting and Quran reference clipsApplication data and reference audio
MongoDB AtlasDatabaseInstitute, student, guardian, and academic records
OpenAIWord transcription for scored practice. Optional staff and study tools when the institute connects its own keyThe recitation clip for that attempt, or the prompt the feature sends
D-IDTalking-face add-on on the web, only when an institute turns it onSession data for that practice
FirebasePush notificationsDevice tokens
GoogleOptional Google sign-inThe account identity used to sign in
BrevoService emailRecipient address and the message
RazorpayFee payments for institutes that use itPayment information for that charge
StripeFee payments for institutes that use itPayment information for that charge
