Security

How the platform protects institute, student, and guardian data.

This page describes how the ilming platform is put together. It is not a certification and it does not promise a particular uptime. Questions: info@ilming.io.

Accounts and access

  • Staff, students, and guardians sign in with their own accounts. Passwords are stored hashed.
  • Roles separate platform admin, institute admin, staff, teacher, student, and guardian.
  • Institute staff only see the modules their role allows. Guardian accounts see the children linked to them.
  • Each institute is a separate tenant. Records are stored against that institute.

Transport and files

  • The site and the app talk to the API over HTTPS.
  • Recitation audio is written to the application server with restricted file permissions and is served through an access-controlled address.
  • Some Quran reference clips are stored in Amazon S3 and opened with time-limited links.

Hosting and backups

The application runs on AWS. Institute records are in MongoDB Atlas. A database backup job runs daily by default. The local backup file is deleted after it uploads. Backups are for recovery of the service. They are not a substitute for an institute export. There is no restore button in the app. Recovery follows a written restore drill on a separate database first. A recording a student has deleted can remain inside an older backup until that backup is no longer kept.

Exams

When an institute enables them, exams can require fullscreen, detect leaving the tab or window, and block copy, paste, and right-click. A required webcam opens the camera on the student device to check that it stays connected. That video is not uploaded and is not used for face recognition. The exam form has a screen-recording option. The current monitor does not capture or upload the screen.

Audio and AI

Scored practice sends the recording to OpenAI for a word transcript of that attempt. ilming does not train models on institute recordings. The talking-face add-on uses D-ID. The private key stays on the server. Detail is in the privacy policy.

Deletion

Students can delete a practice clip or a recording that is still waiting for review. That audio file is removed from the server at that moment. Approved recordings stay for the life of the institute account so the teacher and guardian record remains. They are not deleted on a timer. Students and guardians can close their own account from Settings. An institute leaving ilming can email support to request export and deletion of its tenant data.

If something goes wrong

Report a security issue to info@ilming.io. We will look at it, limit access if needed, and tell affected institutes when the law or the risk requires it.
