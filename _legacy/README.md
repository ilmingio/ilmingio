# Legacy Ilming / Interval tuition website

This folder holds the **previous** static site (~800+ HTML pages) from the Interval Learning template, rebranded partially as “online tuition for all classes.”

It was archived on **May 2026** when the marketing site was rebuilt to match **Ilming LMS** positioning (coaching institute operations).

## Contents

- `content/` — old `blogs/`, `courses/`, `boards/`, `location/`, etc.

## Do not deploy

Deploy the **site root** (`index.html`, `features/`, `about/`, `contact/`, `assets/css/site.css`) — not this folder.

## SEO

If old URLs were indexed, add 301 redirects from your host (see `/_redirects` in site root) or restore specific pages from `content/` as needed.
