System overview

Four repos, one platform

ilming is a multi-tenant Islamic LMS. The marketing site drives leads; the CRM is the operations hub; the API is the single source of truth; the mobile app extends Tahfiz and academy features for students and guardians.

Backend

Ilming-api

Express + TypeScript, MongoDB, Redis, Socket.IO. 52 route modules, JWT auth, multi-tenant institutes.

api.ilming.io
Web app

Ilming-crm

Next.js 15 + React 19. Role portals: admin, institute, teacher, student, guardian.

app.ilming.io
Mobile

Ilming-student-mobile

Expo SDK 57. Virtual Ustadh practice, Hifz desk, academy (courses, exams, fees).

Expo / iOS & Android
Marketing

ilming (this site)

Static marketing site — positioning, pricing, blog, demo documentation.

ilming.io

Core differentiator

Tahfiz / Quran recitation flow

End-to-end digital workflow: teacher assigns verses → student records with AI scoring → teacher reviews → parent sees progress. Same flow on web CRM and mobile app.

Complete Tahfiz lifecycle

sequenceDiagram
    participant T as Teacher / Institute
    participant API as Ilming-api
    participant S as Student (Web / Mobile)
    participant AI as OpenAI Whisper
    participant G as Guardian

    T->>API: POST /recitation/assignments
(surah, ayah range, due date)
    API-->>S: Assignment appears in Tahfiz desk
    S->>API: Socket practice:join + record audio
    S->>API: POST /recitation/attempts
    API->>AI: Transcribe + word-match scoring
    AI-->>API: Score + feedback
    API-->>S: Instant AI result (pass/fail gate)
    API-->>T: Attempt in review queue
    T->>API: Play audio + approve / request re-record
    API-->>S: practice:approval + push notification
    API-->>G: Progress + weekly AI report
1

Teacher creates assignment

CRM: /teacher/tahfiz or Institute: /institute/tahfiz — select student, surah/ayah range, optional reference audio, due date.

2

Student practices (Virtual Ustadh)

Web: /student/tahfiz · Mobile: center Sabk mic → /practice/[id]. Live Socket.IO feedback + Madd/tajweed coaching UI.

3

AI scoring gates the attempt

Whisper transcription + deterministic word-match. Pass → teacher queue. Fail → student re-records with coaching hints.

4

Teacher reviews & approves

Review queue: play student audio, add feedback, approve or request re-record. Push notification to student on approval.

5

Revision plan + Hifz progress

Auto-generated murajaah schedule. Student marks revision items done. Progress stats from approved assignments.

6

Guardian visibility

CRM: /guardian/tahfiz · Mobile: guardian tabs. Weekly AI reports, term reports, live approval status.

Presenter script

15-minute demo path

Recommended flow for Tahfiz-focused demo. Full script with Arabic translations is in the CRM demo guide.

1

Opening (2 min) — Institute overview

Login as Institute → /institute/tahfiz. Show institution-wide stats, weekly trend, assignment overview. Pitch: "One platform for Tahfiz operations — assign, track, report."

2

Teacher assigns (2 min)

Switch to Teacher → Create assignment for a student (surah/ayah). Show review queue with pending attempt.

3

Student practices (5 min) — hero moment

Login as Student → /student/tahfiz → Guided practice. Record recitation, show AI score, coaching feedback. This is the differentiator.

4

Teacher approves (2 min)

Back to Teacher → Play student audio → Approve. Show how attempt moves to approved state.

5

Parent visibility (2 min)

Login as Parent → Quran progress, weekly AI report. "Parents stop calling for marks."

6

Academy extras (2 min) — optional

Quick tour: exams, course materials, fees, live classes, certificates. Mention mobile app for on-the-go practice.

Opening pitch (30 seconds)

"Today we're showing the AI-Powered Quran Learning Platform — a complete digital workflow for Tahfiz institutions. Teachers assign verses. Students record inside the platform and get instant AI feedback on memorization accuracy. Gate-cleared attempts go to the teacher, who plays the audio, then approves or requests a re-record. Parents see live progress and weekly reports. Management sees institution-wide stats from one desk."
